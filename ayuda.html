Ayuda e instalación

Windows x64

  1. Descarga Luma-Setup.exe desde Descargas y ábrelo.
  2. Si Windows muestra Windows protegió su PC, pulsa Más información y luego Ejecutar de todas formas.
  3. Permite la solicitud de administrador del instalador. El instalador copia Luma a Program Files.

Ese aviso aparece porque las versiones de Luma todavía no tienen firma de editor público. Puede aparecer mientras el proyecto obtiene su firma de editor. Descarga siempre desde esta página o desde el release oficial.

Para comprobar que tu archivo es el publicado, calcula su hash en PowerShell y compáralo con SHA256SUMS.txt:

Get-FileHash -Algorithm SHA256 .\Luma-Setup.exe

Linux x64

En Debian o Ubuntu, descarga el paquete .deb e instálalo con tu gestor de paquetes. Para instalar por usuario, extrae el .tar.gz y ejecuta ./install.sh dentro de esa carpeta. Requiere un escritorio X11 o Wayland y OpenGL 3.3.

¿Necesitas ayuda?

Revisa la documentación del launcher o reporta un problema en GitHub. Incluye tu sistema operativo, la versión de Luma y los pasos para reproducirlo. Evita publicar contraseñas o datos personales en los registros.
